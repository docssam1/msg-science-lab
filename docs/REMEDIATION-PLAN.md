2026-09-22 사용자 승인: 원본 6문항별 오개념 후보 분석 → 확인 질문 → 별도 표시한 유사문제 → 재확인 결과.

## 작업 계약

- 제품/저장소: MSG 사이언스 랩 / E:/Codex/work/msg-science-lab. 기존 lete-on과 분리.
- 학습 단계: 초등과학심화 · 초과심_물리 CH01 학습 후 (학년 미지정).
- 선수 지식: 원본 10~15쪽의 부품 역할, 영점, 눈높이, 0~30 N 눈금. 대수식·질량 변환·중력 계산은 요구하지 않는다.
- 원본 daily test 6문항의 질문/선택지/서답형은 변경하지 않는다. 각 문항에 창작 확인 질문 1개와 유사문제 1개를 연결한다.
- 한 번의 오답은 오개념 확정이 아니다. 아는 선택지/부분 이름의 혼동은 후보로, 빈칸·뜻이 불분명한 서답은 판단 유보로 표시한다.
- 단위/진동은 원본 6문항의 직접 평가 범위를 넘어서는 부분이 있으므로 학생의 오개념으로 추론하지 않고 미평가 범위를 알린다.
- 서술 이유는 관찰 사실/주장/근거로 교사가 검토한다. 자동으로 자유 서술을 이해하거나 확정 진단했다고 표현하지 않는다.
- 학생용은 원본 제출 뒤에만 분석에 접근하고 추가 문항도 답을 제출한 뒤 풀이를 연다. 강의용은 교사가 문항을 제시하고 명시적으로 풀이를 공개한다. 교사 공개는 학생의 학습 기록이 아니다.
- 결과의 의미는 이번 확인 질문과 유사문제 범위에 한정한다. 장기 숙달, 학습 효과, 확률 점수는 제공하지 않는다.
- 실제 음성/새 챕터/전체 단원평가/공개 배포는 별도 승인 대상이다.

## 중복 검사와 출처

src/docs/tests의 오개념·유사·misconception·diagnosis 검색에서 현재 구현은 발견되지 않았다. Git main은 최초 커밋 전이며 원격도 없다. 기존 문항 모델/채점/그림/실험 이동을 재사용한다. 별도 출처 카탈로그가 없으므로 docs/CH01-SOURCE-REVIEW.md의 인쇄 쪽과 검토 기록이 근거 지도다. 원본 PDF나 개인 음성은 옮기거나 업로드하지 않는다.

## 중단과 인수인계

사용자는 사용량 표시가 100%로 바뀔 때까지 진행을 요청했다. 현재 도구에는 계정 사용량 표시를 읽는 기능이 없어 그 신호를 자동 감지할 수 없다. 사용자 중단/알림이 오면 정확한 진행 상태와 다음 명령을 남기고 중단한다. 의미 없는 작업으로 사용량을 채우지 않는다.
