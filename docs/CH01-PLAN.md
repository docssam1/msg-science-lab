# CHAPTER 01 시범 수업

사용자 승인: 2026-09-22. 범위는 초과심_물리 PART I 무게 재기 CHAPTER 01.

- 본문 인쇄 10~15쪽을 페이지 이미지로 확인. 10쪽 구조/사용법, 11쪽 눈높이, 12쪽 저울 종류, 13~14쪽 과학 이야기, 15쪽 daily test 6문항.
- 단원평가 인쇄 44~47쪽 20문항과 해설 2~3쪽은 별도 평가로 보존. 시범 수업에서 전체 평가를 미리 공개하지 않는다.
- 구조: 예상, 부품 탐색, 영점, 물체 매달기/진동, 눈높이, 저울 종류, 교재 이야기, daily test.
- 학생용은 제출 후 피드백. 강의용은 교사 공개 버튼, 터치/펜 판서, 전체 화면, 단계 초기화.
- 원본 daily test의 서답형은 서답형으로 유지. 새 연습과 가상 실험은 원본 문항과 구분.
- 가상 저울: 0~30 N, 2 N 단위 눈금. 정성적 원리 설명용이며 실제 교구의 규격을 재현한 것이 아님.
- 영점 오차, 실제 힘, 눈높이에 따른 겉보기 눈금은 별도 상태. 과부하를 실제 측정처럼 표현하지 않는다.
- 13~14쪽 역사/미래 읽기 자료는 원본 링크로 연결하고 추가 연대/성능 주장을 만들지 않는다.
- 디자인: MSG 원본 로고. navy #102f52, turquoise #5bbcc0, brown #88745c, white #ffffff, paper #f3f7f8, ink #16334c.
- 글꼴: 맑은 고딕/시스템 한글 고딕. 큰 저울 한 개를 중심으로, 설명과 조작은 오른쪽. 모바일에서는 한 열.
- 동작: 사용자 조작에 대한 응답만. 정지/장면 전환 때 타이머 해제. 모션 축소에서도 단계별 관찰 가능.
- 검증: 수치/정답 단위 테스트, 학생/강의 정답 가림, touch/pointer/keyboard, 1920/1365/390/320, 인쇄, 콘솔 오류, 영상 재생/정지.
- 아직 범위 밖: 외부 배포/원격 저장소 생성, 전체 8개 챕터, 실제 촬영, 실제 전자칠판 하드웨어 검증.
