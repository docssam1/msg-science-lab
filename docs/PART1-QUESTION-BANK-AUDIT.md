## 현재 창작 처방 은행 감사

- 처방 18개(`s01`~`s18`)는 모두 고정 선택형이다. 생성형 변형, 서술형 채점, 영재원 단계형 은행이라고 부르지 않는다.
- 진단 코드는 M01~M09. M02와 M09는 현재 원본 일일평가 연결이 각각 1문항뿐이므로, 별도 창작 확인 질문 `d02`·`d09`를 한 번씩만 보여 줄 수 있게 했다. 첫 오답과 확인 질문 오답이 모여야 확정된다. 확인 질문 정답 하나로 숙달을 확정하지 않는다. M04의 고유 처방은 `s18`을 추가해 두 문항이 되었지만 연결 원본 일일평가가 없다. 진단을 완성으로 표시하지 않는다.
- `b9`~`b11`은 공식 해설 미확인으로 자동 채점·진단 제외를 유지한다.
- 이 배치에서는 한 번 답한 고정 처방 문항은 맞고 틀림에 관계없이 **새 처방으로 재선택하지 않도록** 로그를 필수 입력으로 바꿨다. 문항 ID와 별개인 변형 키도 기록과 비교해, 앞으로 같은 변형을 다른 ID로 더하더라도 재선택하지 않게 한다. 풀이 화면 안의 재시도는 새 변형 선택이 아닌 같은 문항의 피드백이다. 풀이 가능한 새 문항이 소진되었는데 진단이 확정 상태면 숙달로 승격하지 않고 관련 실험·교사 확인을 안내한다.

회귀의 부정 대조는 과거의 ‘맞힌 ID만 제외’ 선택 규칙을 테스트 안에서 재현해, 틀린 `s01`이 재선택되는 결함을 확인한 다음 현행 선택기에서는 제외되는지 비교한다. 같은 변형 키를 다른 ID에 붙인 합성 목록에서도 한 배치에 한 번만 선택되고, 첫 답변 뒤에는 두 ID 모두 제외되는지 검사했다. Edge의 합성 기록으로 `d02` 오답 → `s03` 오답 → 재진입 시 `s04`만 남음 → 모두 사용 후 교사 확인 안내를 검증했다. 실제 학생 기록이나 교사 음성은 사용하지 않았다.

위 세 문항은 원본 문항이 아닌 **MSG 창작 확인 질문**이다. `s18`은 M04의 별도 처방으로, 흔들리는 동안 읽는 절차를 고치는 4지 선택형이다. d09는 B에서 10 g마다 5 cm 늘어나므로 20 g에 10 cm라는 독립 계산을 기록했다. 안전한 실제 실험을 지시하지 않는다. 네 문항의 문장·보기가 초등과학심화 학습자에게 적절한지는 작성자 외 검수자가 다시 판단해야 하며, 그 전에는 release `locked`다.
