# MSG 사이언스 랩: 캐릭터 동작 시연

2026-09-22 사용자 승인: 안경, 검은 스웨터, 흰 셔츠, 청바지의 2D 만화 캐릭터. 실사/인물화는 사용하지 않는다. 학생 자습용과 강의용은 별도 화면으로 구성한다. 첫 단원은 물리 무게 재기. 기존 lete-on은 수정하지 않는다.

## 이번 범위

독립 로컬 Git 저장소, 승인 캐릭터의 동작 시연, 학생/강의용 웹 진입점, 간단한 용수철 탐구 모형. GitHub 생성/푸시/공개 배포, PPTX, 전체 교재 제작, 실제 목소리 복제는 이번 완료 범위에 포함하지 않는다.

## 디자인

- 주 작업: 실험 관찰과 선생님 캐릭터의 말하기 반응 확인.
- 색상: 잉크 #19394B, 종이 #FFFFFF, 실험실 바탕 #F3F7F9, 물리 악센트 #2C60A4, 눈금 강조 #F1C550, 보조 글자 #657884.
- 글꼴: Windows 환경의 맑은 고딕, 시스템 산세리프. 제목 32px, 본문 17px, 보조 13px. 프로젝터에서는 본문 확대.
- 배치: 조용한 단원 색인 / 넓은 실험 면 / 캐릭터와 짧은 질문. 모바일은 본문 후 캐릭터 순서.
- 핵심 시각물: 승인 만화 선생님과 눈금을 읽을 수 있는 용수철 실험. 배경 장식과 자동 움직임은 최소화.
- 기피: 실사, 얼굴 전체 이미지의 빠른 교체, 배경 재렌더링, 의미 없는 반복 바운스, 답안 자동 노출.

## 움직임과 정직한 표시

캐릭터 원본 이미지는 고정한다. SVG 입/눈 오버레이로 입 닫힘, 반 열림, 크게 열림, 둥근 입, 눈 깜빡임 및 반응 표정을 표시한다. 모션 축소 설정에서는 자동 깜빡임과 입 움직임을 끈다.

무음 시연은 대사 타임라인을 사용하며 반드시 무음으로 표시한다. 로컬 음성 파일을 연결하면 Web Audio RMS 기반 발화/무음 감지를 사용한다. 이는 정밀 음소 정렬이 아니며 파일 음량에 기반한 근사 립싱크다. 일시정지/종료/오류/모드 이동 시 입을 닫는다. 음성 파일은 서버로 업로드하거나 저장하지 않는다.

## 음성

사용자 지정 엔진: https://github.com/k2-fsa/OmniVoice
목소리 참고 링크(사용자 최신 지정): https://www.youtube.com/watch?v=e9NR2QUjMps
참고 구간: 8분부터. 첫 참조로 8:00~8:10 추출을 시도했으나 YouTube 미디어 서버가 HTTP 403을 반환했다. 실제 음성 파일과 전사는 아직 확보하지 못했다. 사용자의 오디오 첨부/로컬 원본 경로 대기 중이다.

이 시연은 OmniVoice 설치/복제 완료를 주장하지 않는다. Google/기기 음성으로 몰래 대체하지 않는다. 실제 생성 음성은 검수 후 파일 연결로 테스트할 수 있다. 현재 기본 Python에는 torch/omnivoice가 없고, GPU는 GTX 1660 SUPER 6GB(확인 당시 여유 약 1.9GB)이므로 별도 실행 환경과 메모리 사용 검토도 필요하다. 기존 프로젝트의 자동 git pull/음성 업로드 스크립트는 실행하지 않았다.

## 교육 내용 경계

용수철 탐구는 동작 확인용 창작 모형이다. 추 1개=1N, 원래 길이 6cm, 1N마다 2cm 늘어난다고 가정하며 모형의 범위는 0~4개다. 전체 길이와 늘어난 길이를 구별한다. 공식 MSG 문항이나 정답의 검수 완료본이 아니다. 원본 PDF는 복사하거나 변경하지 않는다.
