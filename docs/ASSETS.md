# 캐릭터 원본과 제작 기록

- teacher-approved-sheet.png: 사용자가 2026-09-22 승인한 만화체와 표정 시안. 원본 보존 복사.
- teacher-neutral.png: 승인 시안을 참조해 내장 이미지 생성 도구(image_gen)로 만든 정면/닫힌 입 기본 포즈.
- 최종 프롬프트 요지: 승인된 2D 만화 캐릭터의 얼굴, 안경, 머리, 의상과 비율을 유지하고 단일 전신으로 분리. 정면, 닫힌 입, 흰 배경. 입·눈 애니메이션 오버레이를 위한 단순한 피부 표현. 실사/텍스트/추가 인물 금지.
- src/avatar.js: 웹 런타임의 입·눈 SVG 애니메이션 레이어. 원본 PNG를 변형하거나 덮어쓰지 않는다.
- 승인 원본 사진은 새 저장소에 넣지 않았다. 생성 이미지 외 교재/음성 원본은 저장소에 넣지 않는다.
