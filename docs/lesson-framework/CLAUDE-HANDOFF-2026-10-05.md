## 1. 과제와 범위

- 제품: 별도 저장소 `docssam1/msg-science-lab`의 MSG 초·과·심 물리. `docssam1/lete-on`의 독쌤 사이언스 랩과 혼합하지 않는다.

- 수업 방식: 학생은 인쇄한 원본 기반 책을 펴고, 교사는 질문 → 학생 반응 → 그림/실험/영상 공개 → 답 확인하기 → 필요 시 추가 설명 순서로 진행한다. 강의용에는 우루사쌤 자동 음성을 넣지 않는다.
- 현재 요청은 1차시 강의 코드의 `main` 반영과 이 인수인계서 작성이다. **현장 검수·대상 학년 확인까지 완료했다는 뜻은 아니다.**
- 제외: 사진 첨삭·비공개 Drive 제출 게이트웨이, 결제, 3D 자산 재생성, OmniVoice 음성 재생성, Google TTS, 다른 제품 저장소 수정.

## 6. 실행·중지 조건

E:의 최신 `main`을 별도 작업본으로 받아 시작한다. 기존 `work/essay-photo-feedback-boundary-20261003` 브랜치에는 **보류한 사진 게이트웨이 커밋**이 있으므로 통째로 병합하거나 그 브랜치에서 `main`으로 직접 밀지 않는다. G: PDF와 기존 승인 미디어는 읽기 전용이다.

```powershell
npm test
node scripts/local/build-sample-manifest.mjs --check
# 로컬 서버 실행 후 QA_BASE를 해당 주소로 지정
node tests/entry-teacher-browser.mjs
node tests/lesson-stage-browser.mjs
```

브라우저 테스트에는 기존 Playwright 설치 경로를 `MSG_PLAYWRIGHT_URL`로 설정한다. 검수 산출물은 E:에 둔다. 공개 샘플 파일을 바꾸면 커밋된 파일 기준으로 `node scripts/local/build-sample-manifest.mjs`를 다시 실행하고 Pages의 내용 해시 검증까지 확인한다.

다음 중 하나라도 확인되지 않으면 해당 결과는 **검수 대기**로 남긴다: 원본 쪽과 문항, 공식 답 근거, 학습자 수준, 실제 수업 화면, 학생 답 비노출, 기존 미디어 보존. 확인되지 않은 답이나 영재원 문제를 만들어 정답으로 자동 채점하지 않는다.
