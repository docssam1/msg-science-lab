# MSG 초·과·심 물리 1·2차시 — 사이언스랩 검수 인수인계

작성일: 2026-09-26  
대상: `docssam1/msg-science-lab`의 물리 1·2차시 학생용·교사용·실험·영상·인쇄 흐름  
상태: **검수 요청 / 완성 승인 아님**

## 1. 목표와 판단 기준

학생은 책을 전체 화면에서 읽고, 우루사쌤의 자동 안내를 따라 예상·실험·관찰·기록·확인을 스스로 끝낸다. 교사는 교안을 전체 화면으로 열어 곧바로 발문, 자료 공개, 영상 재생, 학생 실험을 진행한다. **우루사쌤의 자동 설명은 스스로 공부하기 전용이며 교사 교안에는 필요 없다.** 학생용과 교사용 교재는 첫 화면에서 바로 선택하고 각각 인쇄할 수 있어야 한다. 아이들이 실제로 나와 두 팀으로 체험하는 수업 흐름을 우선한다.

브랜드는 **MSG 초·과·심**이고 우루사쌤은 안내 캐릭터다. 원본 교재의 문장·읽을거리·평가 18문항과 사용자 제공 표지를 보존한다. 기존 OmniVoice 음성, 교육영상, 승인된 표정은 우선 재사용한다. 새 음성·영상·표정 전체 세트 재생성은 하지 않는다. 원본/실사/가상 실사/도해를 지면에서 명확히 구분한다.

## 2. 이번 검수에서 반드시 고칠 사용자 요구

### 첫 화면과 인쇄

- 첫 화면에 **학생용 스스로 공부하기 / 교사용 현장 강의 / 살아있는 책 / 학생용 인쇄 / 교사용 인쇄**를 읽기 쉬운 큰 선택지로 둔다. 인쇄는 A4 PDF와 브라우저 인쇄로 확인한다.
- 학생·교사 진입 후 각 역할에 맞는 전체 화면이 곧바로 열린다. 세부 도구가 첫 학습 화면을 가리지 않게 한다.

### 학생용 스스로 공부하기

- 자습 자체가 전체 화면 경험이어야 한다. 책이 주인공이며 책 안에서 글·사진·도해를 확대하고 읽던 쪽으로 돌아온다.
- 시작 후에는 매 단계에서 `설명 듣기`를 다시 누르지 않아도 우루사쌤이 등장해 안내한다. 안내 예시: “다음 페이지를 눌러보세요.” “실험을 해볼까요?” “실험 아이콘을 클릭하세요.”
- 해당 실험 아이콘은 안내 시 눈에 띄게 반짝인다. 아이가 누르면 실험이 열리고, 우루사쌤이 그다음 행동을 설명한다. 안내는 실제 조작 상태와 맞아야 한다. 단순 음성 종료만으로 실험·페이지를 자동 통과시키지 않는다.
- 말·표정·자막은 같은 장면을 가리킨다. 소리를 사용할 수 없는 상황에서도 자막과 시각적 강조로 흐름을 이해한다. 시작 화면부터 실제 기기에서 음성 재생과 이어지는 자동 안내를 검증한다.
- 일반 학습 단계는 실험·관찰·필요한 간단 기록에 집중한다. 답 체크·과제 사진 제출·채점 도구를 매 학습 장면에 반복해서 넣지 않는다.
- P5에서 물체를 걸기 **직전** 영점 확인 여부를 검사한다. 미확인 시 첫 경고는 “실험 방법에 오류가 있어요. 어떤 과정을 다시 살펴봐야 할까요?”이며 답을 먼저 알려주지 않는다. 첫 시도와 재시도를 보존한다.

### 일일 테스트·과제 답안

- **일일 테스트와 과제에서만** 학생이 문제 자리의 답을 선택해 체크하거나 직접 입력·필기한다. 답을 쓰기 위해 별도 화면을 찾아다니지 않으며, 다음 쪽으로 갔다 돌아와도 첫 답과 수정한 답이 남는다. 과제 화면은 이번 검수에서 새로 마련할 대상이다.
- 이 두 영역에만 **`사진 찍어 올리기`** 버튼을 둔다. 종이에 쓴 답을 촬영하거나 기존 사진에서 고르고, 올린 뒤 미리보기·교체·삭제를 할 수 있어야 한다. 사진에서 답을 읽어 채점한다면 학생이 문항별 인식 결과를 확인·수정할 수 있어야 한다. 읽지 못한 문항은 임의의 답이나 점수를 만들지 않는다.
- 이 두 영역의 답안 근처에 **`채점하기`** 버튼을 둔다. 누르기 전에는 정답·해설을 숨긴다. 채점 후에는 문항별 ○/×, 학생이 쓴 답, 확인된 정답 또는 재검토 상태, 해설과 관련 실험으로 돌아가는 길을 보여 준다. 공식 정답·해설이 미확인인 문항은 자동 점수를 확정하지 않고 `검토 필요`로 표시한다.

### 교사용 현장 강의

- 교사가 설명의 주체다. 교사용 화면에서 우루사쌤의 자동 등장·자동 음성·다음 단계 안내를 요구하지 않는다. 교사가 필요한 해설·영상·실험을 직접 열고 제어한다.
- 교사용 지도안은 전체 화면에서 즉시 수업 가능한 교안이다. 질문 → 학생 반응 → 자료·해설 공개 → 영상/실험 시연을 한 화면 흐름으로 진행한다. 정답을 학생에게 먼저 노출하지 않는다.
- **교안 위에 직접 쓰기 또는 해설 보기**가 가능해야 한다는 최신 요청을 반영한다. 이 요구는 기존 문서의 “필기가 핵심이 아님”과 다르므로, 검수 시 실제 수업에 필요한 직접 쓰기 범위와 저장·지우기 동작을 확정한다. 필기 도구 구현 여부만으로 교안 전체를 평가하지 않는다.
- 9·10·11쪽 영상은 각 지면에서 바로 보여 줄 수 있어야 한다. 현장 투사 화면에서 영상 종료 후 교안으로 자연스럽게 돌아간다.
- 두 팀 학생이 앞으로 나와 동일한 조건의 가상 저울 두 개를 각각 조작한다. 예상·측정 기록은 팀별로 독립이다. 교사는 가상 설정값 확인 또는 실물 대조 후 ○/×를 표시한다. `새 대결`은 다른 물건 세트로 바뀌고 기록을 초기화한다.
- 실험은 2개로 나누어 독립 복사·진행할 수 있어야 한다는 요청도 검수한다. 각 복사본의 기록과 조작 상태가 섞이지 않아야 한다.

### 교재 지면과 원본 충실도

- 초등학생이 읽기 좋도록 강조 낱말은 크게·진하게, 본문은 답답하지 않게 배치한다. 둥근 테두리, 세로형 제목, 잡지 같은 리듬을 사용한다. `본책 13쪽`처럼 학생 지면에 노출된 편집용 색인 문구는 제거한다.
- 9·10·11쪽 읽을거리는 **원본 텍스트를 보존**한다. 10쪽 시계 속 태엽은 실제 내부 사진, 11쪽 극소 코일·4D 프린팅·2D 재료는 내용과 맞는 이미지로 보여 준다. 가상 실사는 실제 연구 사진처럼 오인되지 않게 표시한다. 세 쪽 모두 기존 영상과 연결한다.
- Daily Test는 원본의 문항·그림·보기·두 열 배치와 문항별 세로 간격을 대조한다. 문제를 위쪽에 몰지 않는다. “원본 1–4번” 같은 편집용 표현을 학생 지면에서 쓰지 않는다. 마지막 시험면은 읽을 만한 글자·그래프 크기로 확인한다.
- 본문 실험 A(10/20/30 g → 3/6/9 cm)와 평가 12번 B(10/20/30 g → 4/8/12 cm)를 섞지 않는다.

3. **교사용 현장 교안:** 교사 투사 화면의 질문·자료·해설·영상·실험, 직접 쓰기 또는 해설 보기, 2팀 체험, 독립 실험 복사와 새 대결을 실제 수업 순서로 구현한다.
4. **원본·인쇄 재검수:** 9–11쪽 원문/이미지/영상, Daily Test 18문항의 원본 배치, 학생/교사 PDF의 A4 페이지별 글자 크기·넘침·QR을 대조한다.
5. **완료 게이트:** 390px 학생 터치, 1366/1920px 교실 투사, A4 인쇄, 음성·영상 동기, 2팀 실제 조작, 실기기 QR 스캔을 확인한다. 일일 테스트·과제에서만 답 선택·직접 쓰기·사진 선택/촬영/교체/삭제·필요 시 문항별 인식 확인·`채점하기`·재방문 시 답 복구를 실제 기기에서 검증한다. 일반 학습 장면에는 사진·채점 도구가 나타나지 않아야 한다. 공식 Daily Test 9–11번 해설, 대상 학년과 지도 조건, 본책 p17의 `반비례` 표현은 교육 검토가 끝날 때까지 미승인으로 표시한다. 검수 결과와 사용자 승인 후에만 추가 병합·공개 완료를 판단한다.

검수자는 각 항목을 **통과 / 수정 필요 / 확인 불가**로 기록하고, 수정 필요 시 쪽·화면 크기·재현 순서를 남겨야 한다. 기존 브라우저 자동검사 통과를 이 새 요구의 통과로 대체하지 않는다.

## 6. 검수 브랜치의 학생 자동 안내 구현 (2026-09-26)

3절의 기존 화면 설명은 `main` 기준이다. 별도 `review/science-lab-handoff-20260926` 브랜치에는 다음 기능을 구현했다. **검수·승인 전이므로 `main`에는 병합하지 않는다.**

- 학생용을 열면 책이 화면 높이를 쓰고, 우루사쌤의 시각 안내가 바로 나타난다. 책 안에서 스크롤하고 `본문 크게`를 눌러 확대한다.
- 다음 쪽이나 실험이 필요한 때에 우루사쌤이 그 행동을 안내하고 해당 버튼이 반짝인다. 아이가 실험을 누르면 활동을 열고 그 활동에 맞는 다음 조작을 안내한다. 조작·답 제출은 자동으로 통과시키지 않는다.
- 처음 화면의 안내는 글과 승인된 표정으로 즉시 보인다. 학생이 페이지를 넘기는 등 처음 조작한 뒤에는 해당 장면의 **기존** OmniVoice 음성이 연결된 경우 자동 재생을 시도한다. 새 안내 문장에 음성 클립이 없는 곳은 글로 안내하며 새 음성을 만들지 않았다.
- 교사용에서는 우루사쌤 자동 안내와 음성 버튼을 숨겼다. 교사가 수업을 직접 진행한다.
