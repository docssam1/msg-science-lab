# 초·과·심 물리 1차시 강의안 · 근거/검수표

상태: **강의 순서 구현·자동 검수 완료, 현장 수업 검수 전**. Git 반영이나 정적 사이트 배포는 교실 사용 승인과 별개입니다.

## 강의 계약

- 대상: 초등 과학 심화. 정확한 학년·선행 수준은 아직 확인 필요.
- 사용 방식: 학생은 인쇄 교재를 펴고, 교사는 16:9 가르치기 화면을 투사합니다. 별도의 교사 노트 창에는 발문 순서와 검수 주의가 장면과 동기화됩니다.
- 투사 화면: 먼저 질문을 보여 주고 학생 반응을 듣습니다. 답과 추가 설명은 교사가 각각 눌러 공개합니다. 그림을 누르면 해당 실험·영상이 열립니다. 교사용 자동 음성은 꺼져 있습니다.
- 핵심 순서: 구조(P1) → 빈 저울 기준(P2) → 저울 필요성(P3) → 다섯 물건 예상(P4) → 직접 측정(P5) → 눈금 읽기(P6) → 저울 종류(P7) → 읽을거리·영상(P8~P10) → 일일 테스트(P11).
