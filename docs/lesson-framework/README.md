# MSG 초·과·심 물리 — 용수철/무게 재기 설계 기준 v2

상태: **설계 확정본 / Work 구현 전 기준 문서**  
범위: 원본 교재의 용수철저울·용수철 성질 두 차시.  
중요: 이 브랜치에서는 설계를 고정한다. 공개 운영 사이트와 기존 음성/영상 자산을 무조건 재생성하지 않는다.

## 0. 최우선 원칙

1. 브랜드명은 **MSG 초·과·심**이다. “우루사쌤 사이언스 랩”을 교재 브랜드명으로 쓰지 않는다. 우루사쌤은 수업 캐릭터/음성 역할이다.
2. 표지는 **사용자 제공 원본 초·과·심 물리 표지**를 그대로 사용한다. 새 표지를 임의 제작하지 않는다.
3. 학생 교재는 설명서가 아니다. **실사/정확한 도해를 크게, 문장은 짧게, 관찰·조작·기록이 중심**이어야 한다.
4. 기존 Science Lab의 강점인 **외곽 프레임, 꼭지 띠, 개념/주의/기록 박스, QR, 사진 중심 지면**을 계승한다. 단, 색을 “학원 색”으로 설명하지 않는다.
5. 제목·그림·짧은 캡션·표 머리글은 가운데 정렬. 긴 본문·교사 메모는 왼쪽 정렬. 표 셀은 내용 성격에 맞춰 가로/세로 정렬을 정확히 맞춘다.
6. 기존 35쪽처럼 설명을 늘리지 않는다. **최종 학생용은 원본 표지를 포함 약 24쪽**을 기준으로 한다.
7. 불필요한 기존 33쪽과 반복 설명 지면은 삭제한다.
8. 사용자 지정 표현 수정: 해당 척도/표현은 “높음”이 아니라 **“매우 높음”**으로 표기한다.
9. 원문과 원본 평가 18문항은 삭제하지 않는다. 추가 탐구는 원본과 분리해 표시한다.
10. 페이지 넘김 자체를 학습으로 보지 않는다. 가르치기와 스스로 공부하기는 별도 진행 로직을 가진다.

## 2. P5 ‘직접 측정해 봐요’ — 영점 게이트는 구현 필수

학생이 물체를 고리에 거는 **그 순간** 빈 저울의 영점 확인 여부를 검사한다.

### 정상
1. 물체 없음.
2. 학생이 0을 확인/조절함.
3. 물체를 건다.
4. 표시자가 흔들림.
5. 안정 후 학생이 눈금을 읽고 값/단위를 기록한다.
6. 다음 물체.

### 영점 미확인 또는 기준 불일치
- 물체를 걸려고 한 순간 측정을 시작하지 않는다.
- 첫 피드백은 정확히:
  **“실험 방법에 오류가 있어요. 어떤 과정을 다시 살펴봐야 할까요?”**
- **“영점을 맞추세요”라고 바로 답을 말하지 않는다.**
- 물체를 내려놓게 하고 학생이 저울의 준비 과정을 스스로 점검한다.
- 학생이 영점을 맞춘 뒤 다시 물체를 걸어야 측정이 시작된다.
- 경고를 닫거나 숫자만 수정하는 것으로 통과시키지 않는다.
- 자동 영점 보정 금지.
- 정상 측정 학생에게 인위적 오류를 만들지 않는다.
- 예측 불일치와 측정 방법 오류를 같은 “틀림”으로 취급하지 않는다.
- 첫 시도/점검/재시도를 기록할 수 있으면 보존한다.

이 동작은 인쇄 지면에서 긴 설명문으로 쓰지 않는다. 교재에는 **“물체를 걸기 전 기준을 확인했나요?”** 수준의 짧은 시각적 체크만 두고, 실제 경고/분기는 웹 실험에서 실행한다.

## 3. 지면 조판 규칙

### 형태
- A4 세로.
- 바깥 프레임/테두리가 분명히 보인다.
- 꼭지 제목 띠 + 본문 + 개념/관찰/주의/기록 박스의 위계를 사용한다.
- 실사와 정확한 도해가 지면의 주인공이어야 한다.
- 사진 밑 캡션은 1줄 중심.
- “이 책에서는…”, “우리는…” 같은 설명문으로 빈 공간을 채우지 않는다.
- 한 쪽에 학습 목적 1개를 우선한다.

### 정렬
- 큰 제목: 가운데.
- 실사/도해: 가운데.
- 짧은 캡션: 가운데.
- 표 머리글/번호/단위: 가운데 + 세로 가운데.
- 긴 설명/발문/교사용 주석: 왼쪽.
- 줄 간격과 셀 내부 여백을 균일하게 유지.
- 표/그림의 왼쪽·오른쪽 기준선이 본문 그리드와 맞아야 한다.

### 이미지
- P3/P4 생활 물건 5개, P7 저울 3종, P8~10 역사/시계/미래, P13~19 2차시 주요 개념은 **실사 우선**.
- 실사 부재 시, 실제 구조를 왜곡하지 않는 정확한 도해.
- 실사와 가상/모형 이미지는 캡션에서 구분.
- 저해상도 역사 기록영상은 “기록영상”으로 표시하고 고화질 실사처럼 꾸미지 않는다.

## 4. 가르치기 / 스스로 공부하기

### 가르치기
- 16:9 전자칠판.
- 한 장면 한 질문.
- 교사가 단계별로 공개.
- 답을 처음부터 띄우지 않는다.
- 학생 조작이 필요한 장면은 교재 사진을 크게 띄우는 것으로 대체하지 않는다.
- 교사 노트는 학생 투사 화면과 분리.
- P5 영점 게이트를 대표 학생 조작으로 실행 가능.

### 스스로 공부하기
- 예상 → 조작 → 기록 → 피드백 → 재확인.
- 답을 제출하기 전 정답/원인 선공개 금지.
- 학생 입력과 첫 시도를 보존.
- P5에서 영점 미확인 시 중립 경고 → 자기 점검 → 다시 걸기.
- 영상/음성이 끝났다는 이유로 자동 다음 단계 금지.
- 중단 후 돌아와도 페이지/실험 상태를 복구.

### 살아있는 책
- 원본/새 교재 지면을 읽다가 활동이 필요할 때 책이 작아지고 실험/영상이 옆에 열린다.
- 활동 후 읽던 위치와 학생 기록을 유지한 채 복귀.
- 갑작스러운 팝업처럼 보이지 않게 한다.

## 5. 음성·표정·교육영상 자산 — 처음부터 재생성 금지

보존 자산 기준 브랜치: **work/urusaem-voice-expressions**

기존 파일을 먼저 스캔한다:
- `sample-v2/audio/voice-library.json`
- `sample-v2/audio/narration-manifest.json`
- `sample-v2/audio/*.mp3`
- 승인된 우루사쌤 표정 이미지
- 기존 `sample-v2/media` 또는 현재 페이지가 참조하는 영상

### 재사용 순서
1. 새 장면/대본을 기존 clip의 `text_sha256`과 비교.
2. hash가 맞으면 **그대로 재연결**.
3. hash가 없어도 정규화한 대사가 완전히 같으면 기존 clip 재사용.
4. 문장 위치만 바뀌었으면 파일을 새로 만들지 않고 scene→clip 매핑만 변경.
5. 화면 자막/사진만 바뀌고 발화가 같으면 음성 재생성 금지.
6. 기존 영상이 같은 관찰 목적을 충족하면 기존 파일과 구간을 재사용.
7. **실제 발화가 바뀐 클립 또는 자산이 없는 장면만 신규 생성**.
8. 신규 생성도 전체 세트가 아니라 필요한 clip 단위로만.
9. 중복 파일 생성 금지.

### 이미 확인된 대표 재사용 후보
- `l1-structure`
- `l1-use`
- `l1-eye`
- `l1-scales`
- `l1-name`
- `l1-past`
- `l1-watch`
- `l1-future`
- `l1-test-a`, `l1-test-b`
- `l1-inquiry`, `l1-inquiry-record`
- `l2-elastic`
- `l2-compress`
- `l2-measure`
- `l2-graph`
- `l2-tools`
- `l2-test-a`, `l2-test-b`, `l2-test-graph`
- 기존 part/reading/fixed 클립은 문장이 맞을 때 재사용

### 금지
- 브라우저 기기 TTS로 조용히 fallback 금지.
- 코/얼굴 위에 SVG 입 모양을 덧그리는 방식 금지.
- 승인된 우루사쌤 표정 세트를 다른 캐릭터 자산으로 대체 금지.
- 음성을 못 찾았을 때 다른 목소리로 자동 대체 금지.

### 기존 교육영상 우선 재사용
현재 구현에서 이미 사용 중인 적합한 영상은 재다운로드/재생성보다 기존 파일을 우선 사용한다.
- **How a Watch Works (1949)**: 시계/태엽 장면. 기존 사용 구간을 우선 검토.
- **Hookeslawexample**: 용수철 변화 관찰용. 본문 10/20/30 g 수치를 증명하는 영상으로 오인시키지 않는다.
- YouTube 광고형 재생을 핵심 수업 흐름에 넣지 않는다.

## 6. 원본 데이터 잠금

- 본문 데이터 A: **10/20/30 g → 3/6/9 cm**
- 평가 12번 데이터 B: **10/20/30 g → 4/8/12 cm**
- 서로 다른 데이터 ID/그래프 상태를 사용한다.
- 추가 40 g은 데이터 A 관계가 이어진다는 조건의 “확장 탐구”로만 사용.
- 원본 1차시 6문항 + 2차시 12문항 = 18문항 모두 유지.

- p19 생활 도구: 제품마다 실제 내부 구조가 다를 수 있으므로 일반화 금지.
- 원본 평가 9~11번: 조건과 기대 답을 원본 그림과 다시 대조 후 해설 고정.
- 실물 실험에서 시스템이 관찰할 수 없는 눈높이/기울기를 “감지했다”고 허위 판정하지 않는다.

## 8. Work 구현 순서

1. **기존 자산 인벤토리 생성** — 음성/영상/표정/실사/도해를 파일별로 목록화하고 재사용 가능/대본 불일치/미확보를 표시.
2. 24쪽 학생 교재를 위 페이지 설계대로 조판.
3. 학생 교재 기준으로 강사용 교안 페이지/발문을 연결.
4. “가르치기” 화면을 독립 장면 구조로 구현.
5. “스스로 공부하기”를 입력/조작/기록 중심으로 구현.
6. 살아있는 책에 같은 장면/상태를 연결.
7. 기존 clip/video/expression을 먼저 연결.
8. 누락된 음성만 신규 생성.
9. P5 영점 게이트 및 재시도 로그 테스트.
10. 원본 18문항/데이터 A·B 격리/QR/인쇄/PC·전자칠판 화면 검수.
11. 검수 통과 전에는 main 병합/완성 표시 금지.

### Work 완료 판정
- 학생 교재가 “설명 문서”가 아니라 실제 교재처럼 보인다.
- 주요 개념 지면이 실사/도해 중심이다.
- P5에서 영점 없이 물체를 걸면 즉시 중립 경고 후 자기 점검으로 돌아간다.
- 가르치기/스스로 공부하기의 진행 방식이 실제로 다르다.
- 기존 음성·영상·표정이 우선 재사용되며 중복 재생성이 없다.
- 원본 18문항과 두 데이터셋이 보존된다.
- 공개 전 PDF 전 페이지와 주요 화면을 시각 검수한다.
