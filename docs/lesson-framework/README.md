# 우루사쌤 사이언스 랩 — 교안 중심 전체 틀 v1

상태: **수업 구조 검토본**. 완성 교안·확정 대본·음성 연결·운영 배포가 아니다.

사용자 최신 지시: 책만 넘기는 방식의 반복을 중단하고, 전체 수업 틀과 교안부터 만든 뒤 대본을 작성하여 음성을 넣는다. 워크플로는 필요한 검수에만 사용한다.

## 현재 작업 경계

- 이 work 브랜치는 `a83106993b75dad04634954b0c82abd7cf147bc3`에서 분리한 문서 작업이다. 운영 사이트, 기존 PDF, 실험 코드를 변경하지 않는다.
- `work/urusaem-voice-expressions`의 기존 코드·생성 음성은 보존한다. 새 교안·대본과 대조하기 전에는 병합하거나 완성본으로 표시하지 않는다.
- 새 음성 생성과 자동 배포는 보류한다. 기존 작업이 완료된 상태를 취소했다고 표현하지 않는다.
- 핵심 장면 28개는 **고정 슬라이드 수가 아니다**. 긴 이야기·실험·평가는 대본 검토 후 여러 장면/화면으로 나눌 수 있다.

## 제작의 기준점

**교안 → 장면별 대본 → 음성·표정 → 앱 연결 → 실제 수업 검수**

화면 하나마다 다음이 있어야 한다: 핵심 질문 / 강사 행동 / 학생 행동 / 학생이 남길 근거 / 그림·영상·실험의 역할 / 기다림 / 다음 단계로 넘어갈 조건 / 원본 근거 / 아직 보여주지 않을 답.

페이지를 넘기는 것, 음성이 끝난 것, 버튼을 누른 것만으로 학습을 완료한 것으로 취급하지 않는다.

| 형식 | 역할 | 답과 진행 |

## 1차시 — 저울로 공정하게 비교하고 설명하기

중심 질문: **눈으로 예상한 순서와 믿을 수 있는 측정 결과는 어떻게 다른가?**

| L1-01 | 저울은 왜 필요할까요? | 느낌으로 비교하기 어려운 점을 말하고 예상으로 이동 |

다섯 대상은 **신발 한 짝, 사과 한 개, 귤 두 개 한 묶음, 휴대폰 한 개, 필기구가 든 필통**이다. 다섯 개 전체를 한 번에 줄 세운다. 익명 주머니나 2개+3개 분할로 되돌리지 않는다. 무게를 새로 확정하지 않으며 기존 가상 설정은 실측값이 아님을 구분한다. 같은 받침을 쓰더라도 받침의 질량·기준 위치를 어떻게 처리하는지 교구 설계에서 명확히 한다.

## 방법 오류 안내 계약

첫 안내는 정확히 다음 문장을 사용한다.

> 실험 방법에 오류가 있어요. 어떤 과정을 다시 살펴봐야 할까요?

- 조작 전·중 영점의 정오, 원인 또는 자동 교정값을 먼저 공개하지 않는다.
- 정상 측정에 임의의 오류를 만들지 않는다.
- 예측 불일치, 측정 방법 오류, 눈금 읽기·입력 실수, 확인할 개념을 별개 상태로 둔다.
- 내부 판정은 실제 기록 가능한 교구 상태에 근거한다. 기록·센서가 없는 학생의 실물 시선이나 기울기를 시스템이 안다고 가정하지 않는다.
- 학생 자기 점검 → 바꿀 방법 → 재측정 → 결과 비교 → 마지막 원인 설명으로 진행한다.
- 첫 기록과 재측정을 보존한다. 정답 순서가 우연히 맞는 것과 측정값이 정확한 것은 다르다.
- 틀린 횟수만으로 오개념을 확정하지 않고 확인 질문과 재확인 문제로 구분한다.

## 장면별 대본 양식 — 아직 음성 생성용이 아님

각 장면을 다음 항목으로 작성한다.

1. sceneId, 원본 쪽/문단/문항과 추가 부분의 구분
2. 화면의 첫 상태와 무엇을 아직 숨기는지
3. 우루사쌤 발화 원고(최종 문장)
4. 발화와 함께 강조·확대할 대상
5. 학생이 답하거나 조작할 대기 지점
6. 응답/관찰별 다음 질문과 피드백
7. 다음으로 넘어가는 조건 및 원래 지면 복귀점
8. 승인 표정 자산 ID와 전환 시점
9. 대본 revision과 검수 상태
10. 그 revision에서 생성한 음성 manifest·길이·발음 검수

모든 발화의 작성과 내용 검토가 먼저다. PDF 본문을 통째로 읽는 기능을 장면 대본의 대체물로 쓰지 않는다. 승인된 표정 이미지를 사용하고 코 위에 입 도형을 겹쳐 그리는 방식을 금지한다. 생성 음성 오류 때 기기 TTS로 조용히 대체하지 않는다.

## 장면·매체 운영

질문 장면, 비교·배열 장면, 부품 확대, 조작 실험, 결과 표, 그래프 작성, 역사 타임라인·기록영상, 적용 문제, 서술형 정리의 구성을 구분한다. 같은 카드 배치에 제목만 바꾼 반복 화면을 만들지 않는다.

설명·시각 강조·영상의 종료는 다음 설명이나 질문을 준비할 수 있지만 학생이 생각하고 답하는 시간을 자동으로 넘기지 않는다. 책과 실험 전환은 같은 작업 맥락에서 부드럽게 이어지고 읽던 쪽·학생 입력·첫 시도 기록을 보존한다. 소리가 없어도 질문과 활동이 이해되는 화면을 먼저 만든다.

영상은 해당 질문에 답할 관찰 단서가 있어야 한다. 저해상도 기록영상, 실사, 자체 애니메이션, 이상적 3D 모형을 구분한다. 적합한 자료가 미확보면 '확보 완료'로 쓰지 않고 매체 요구를 남긴다. 원음 제거가 재사용 권한을 대신하지 않는다.

## 내용 검토 보류표

- R01: 본책 13–14쪽의 연대·최초·성능·미래 수치. 원문과 설명 보완을 분리하고 외부 검증 없이 확정 발화로 만들지 않는다.
- R02: 본책 17쪽의 '반비례'. 전체 길이/줄어든 길이와 조건을 확인하여 주석 필요성을 검토한다. 원문을 조용히 덮어쓰지 않는다.
- R03: 19쪽 도구의 내부 작동과 철사 굵기/코일 지름. 모든 제품에 같은 구조를 적용하지 않는다.
- R04: 20–21쪽 평가, 특히 9–11번의 조건을 원본과 다시 대조한 뒤 해설을 확정한다.
