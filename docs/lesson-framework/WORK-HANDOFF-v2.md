# Work handoff — MSG 초·과·심 물리 1·2차시

구현 기준은 같은 폴더의 README.md v2가 단일 진실원본이다.

## 절대 먼저 하지 말 것
- 전체 음성 재생성
- 영상 재다운로드/재생성
- 새 표정 세트 제작
- main 직접 수정/배포
- 기존 35쪽 PDF를 그대로 미세수정

## 첫 작업
1. work/urusaem-voice-expressions에서 voice-library.json / narration-manifest.json / 표정 / 영상 자산을 인벤토리화한다.
2. 새 24쪽 페이지와 기존 clip을 text_sha256/정규화 문장으로 매칭한다.
3. 재사용률을 먼저 보고한다.
4. 학생용 P0~P23을 실사 중심으로 조판한다.
5. P5 영점 게이트를 구현한다.
6. 그 뒤 teach/self/book을 연결한다.

## 사용자 검수 우선 페이지
P1 구조 / P2 영점 / P3~P5 실사 비교·직접 측정 / P13~P17 힘·탄성·표·그래프 / P19 생활 속 용수철.

## 중요한 문구
영점 미확인 상태에서 물체를 걸려고 할 때:
“실험 방법에 오류가 있어요. 어떤 과정을 다시 살펴봐야 할까요?”

정답인 “영점”을 첫 경고에서 직접 말하지 않는다.

## 자산 재사용 핵심
기존 OmniVoice, 승인 표정, 교육영상, 설명음성은 처음부터 다시 생성하지 않는다.
대본이 실제로 달라진 clip만 개별 생성한다.
브라우저 TTS fallback과 SVG 가짜 입 오버레이는 사용하지 않는다.
