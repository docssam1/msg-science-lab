# MSG 초·과·심 물리 1·2차시 — 구현·검수 기록

기준: `README.md`와 `WORK-HANDOFF-v2.md`, 이후 사용자 피드백. 작업 브랜치 `work/lesson-framework-first`. 원래 계획은 학생 약 24면이었으나, 원본 Daily Test의 두 열과 문항별 간격을 유지하고 마지막 시험 지면을 합치라는 최신 요청에 따라 **학생용 21면, 강사용 41면**으로 조판했다. 2026-09-25 사용자 요청으로 `main`에 병합했다. 아래의 교육 내용·실기기 검수 보류는 병합만으로 해소되지 않는다.

## 구현

- 기존 OmniVoice 음성, 교육영상, 승인된 우루사쌤 표정을 재사용했다. 보존 목록의 파일 113개를 현재 파일과 SHA-256으로 비교했고 모두 일치했다. 새로 생성한 음성·영상·표정은 없다.
- 원본 PDF 앞표지를 P0에 사용했다. 원본 문항 18개는 P11·P19·P20에 한 번씩 들어간다. 문제는 원본처럼 두 열에 나누고, 같은 열 안에서도 각 문항의 시작 위치에 간격을 두었다. 마지막 7–12번은 한 면에 합치고 글자와 그래프를 키웠다.
- 학생 지면의 도해와 사진을 키웠다. 구조 그림은 여섯 부분을 읽을 수 있는 벡터 도해로, 빈 저울은 추 없이 그렸다. 잡아당기기·누르기·놓기, 재질·철사 굵기·코일 지름의 그림은 서로 다른 조건과 움직임을 보여 준다.
- 9–11쪽 읽을거리는 원문 문장을 유지하고 큰 핵심 낱말, 두 열, 세로 제목, 둥근 테두리로 조판했다. 10쪽 태엽은 실제 자동 시계의 태엽 사진(Hustvedt, CC BY-SA 3.0)으로, 11쪽 극소 코일·4D 프린팅·2D 재료는 출처를 밝힌 가상 실사 이미지로 바꿨다. 세 쪽 모두 기존 영상으로 연결된다. 11쪽 영상은 미래 기술 실물이 아닌 현재 용수철의 운동 관찰이라고 명시했다.
- P5는 빈 저울의 기준 확인 없이 물체를 걸면 힘을 적용하지 않고 지정된 첫 경고를 보여 준다. 첫 시도·자기 점검·조절·재시도 기록을 보존한다.
- 현장 강의용 교안은 질문을 먼저 보여 주고 자료와 정답을 따로 공개한다. 교사 노트는 별도 화면에 둔다. 2팀 배틀에서는 같은 가상 저울을 두 개 나란히 띄워 팀별 예상·측정 기록을 분리하고, 가상 교구 정답 또는 교사의 실물 대조 결과를 ○/×로 표시한다. 자습은 예상→조작→기록→피드백→재확인, 살아있는 책은 읽던 면을 유지한 채 옆에서 활동과 큰 글씨 읽기를 연다.
- 본문 실험 A(3·6·9 cm)와 평가 12번 B(4·8·12 cm)는 별도 그래프와 저장 키를 사용한다.

## 공개 전 남은 확인

1. **공식 해설:** 연결된 《초과심_물리_정답과해설》 PDF의 파일 ID·이름·크기를 원본 기록과 다시 대조했다. 확보된 해설 지면은 이 Daily Test 18문항이 아닌 무게재기 단원평가 20문항 구성이다. Daily Test 9–11번의 공식 정답·해설이 확인될 때까지 자동 채점에서 제외하고 교사 노트에 `해설 검토 필요`를 남긴다. 본책 p17의 `반비례` 표현도 전체 길이와 변한 길이를 구분해 교육 검토한다.
2. **대상 학년:** 정확한 학년과 실제 도구 사용 지도 조건이 아직 확인되지 않아 언어 수준·안전 지도 승인은 보류한다.
3. **자산 내용·출처:** 기존 OmniVoice 전체 클립 청취, 교육영상 전 구간 시청, 역사·미래 서술의 시점과 출처 및 추가 사진의 재배포 조건은 별도 확인이 필요하다. 사진별 출처는 `sample-v2/photos/CREDITS.md`에 적었다.
4. **현장 수업:** 실제 교실의 투사 화면에서 교사가 발문·자료 공개를 진행하고 두 팀 학생이 각각의 실험을 조작하는 흐름은 아직 확인하지 않았다. 390px 터치는 Edge 에뮬레이션에서 확인했다. 필기·펜 기능은 이 강의용 교안의 검수 기준이 아니다.
5. **공개 QR:** QR은 공개 `main` 사이트를 가리킨다. 병합 전에는 새 교재 파일 `lesson-print-pages.js`가 404였지만 병합 후에는 공개 파일 240개 내용 해시가 원격 저장소와 일치했고 QR 대상 주소 20개가 모두 HTTP 200이었다. 전 QR의 실기기 스캔과 각 활동의 동작은 별도로 확인한다. 기존 검토본에는 `공개 전 QR`로 표시돼 있다.

따라서 로컬 구현과 인쇄·브라우저 검수, 공개 정적 파일·QR 주소 확인은 마쳤지만 공식 해설·학습자 수준·실기기에서의 QR 활동 검수는 남아 있다. 교육 내용·실기기 검수를 마치기 전에는 최종 완성으로 표시하지 않는다.
