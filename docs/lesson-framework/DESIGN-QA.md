# MSG 초·과·심 물리 1·2차시 — 구현·검수 기록

기준: 이 폴더의 `README.md` v2와 `WORK-HANDOFF-v2.md`. 작업 브랜치 `work/lesson-framework-first`, 시작 HEAD `d5b517b`. 이 기록은 직접 실행한 검수와 보류 사항을 구분한다. **공개·main 병합 승인 상태가 아니다.**

## 구현 결과

- 기존 자산 인벤토리 후 보존 브랜치의 동일 해시 MP3 87개와 승인 표정 6개 및 매니페스트를 누락분만 복구했다. 기존 3종 영상은 원래 파일을 유지했다. 전체 음성·영상·표정을 다시 만들지 않았다.
- 원본 PDF 앞표지를 추출해 P0에 사용했다. 추출 방식과 SHA-256은 `sample-v2/README.md`에 적었다.
- 학생 P0–P23 A4 24면, 교사용 학생 지면+노트 A4 47면을 만들었다. P3–P5 실사 5개, P7 저울 실사 3개, P19 실사 5개와 완력기 정확한 개념 도해를 사용했다. P8–P10은 원본 역사 자료·기존 영상 스틸·개념 도해를 구분해 표시했다.
- P5는 물체를 거는 순간 영점 확인을 검사한다. 실패하면 힘을 적용하지 않고 지정한 첫 경고를 보여 주며 첫 시도, 자기 점검, 재시도를 보존한다.
- 가르치기 질문 우선 공개와 별도 교사 노트, 스스로 공부하기 예상→조작→기록→피드백→재확인, 살아있는 책의 활동 옆 열기와 읽던 쪽 복원을 연결했다. P18에는 재질·철사 굵기·코일 지름 중 한 조건만 선택하고 관찰을 저장하는 활동을 분리했다.
- 학생 지면에 평가 18문항을 한 번씩 편성했다. 본문 A(3·6·9 cm)와 평가 12번 B(4·8·12 cm)는 별도 그래프·저장 키를 쓴다.

## 공개 전 남은 검수·판단

1. **원본 해설:** 제공된 《초과심_물리_정답과해설》 PDF는 이 일일평가 18문항의 공식 해설이 아니라 별도 20문항 구성이다. 평가 9–11번의 조건과 정답·해설을 확인할 공식 자료가 필요하다. 현재 자동 채점은 9–11번을 제외하고, 교사 노트는 `해설 검토 필요`로 표시한다. 본책 p17의 `반비례` 표현도 전체 길이와 변한 길이를 구분해 교육 검토한다.
2. **대상 학생:** 정확한 학년·수준과 실제 도구 사용 지도 조건이 제공되지 않았다. 언어·선행 경험·안전 지도에 대한 학습자 적합성 승인은 보류한다.
3. **자산 전수:** 남은 OmniVoice 클립과 교육영상 구간의 전체 청취·시청, P8 역사/P10 미래 서술의 출처·시점 재검증, 추가 사진의 재배포 조건 확인이 필요하다. 실사 사진의 촬영자와 라이선스는 `sample-v2/photos/CREDITS.md`에 적었다. P19 완력기는 사진 대신 개념 도해이며 그렇게 표기했다.
4. **실기기·입력 경로:** P5의 마우스 드래그/터치 취소/고리 밖 놓기, 모든 활동의 390px 하단 스크롤과 실제 16:9 전자칠판 멀티터치를 추가 확인한다. 터치 탭은 Edge 에뮬레이션으로 통과했다.
5. **공개 QR:** 검수 완료 후 공개 사이트에 새 버전이 반영된 다음 인쇄 QR 전수를 실제 주소에서 다시 시험한다. 그 전에는 QR을 새 수업의 검수 통과로 표시하지 않는다.

따라서 구현과 주요 로컬 동작은 검수했지만 위 승인 항목이 남아 있다. `main` 병합·공개·완성 표시를 하지 않는다.
