## Daily Test 정책

- 교재 33쪽은 문항 하나(13칸)이고 **정답이 인쇄돼 있지 않습니다**. 1g 칸만 예(오른쪽 접시에 1g 추)가 그려져 있습니다.
- 자동 채점하지 않습니다(`kind:'draw'`, `figure:'pans'` → 항상 `검토 필요 · 교사 확인`, 점수·분모 제외, 진단·처방 없음). 학생 화면의 단추는 “내 기록 확인하기”이고 결과 화면은 “채점할 수 있는 문항이 아직 없어요”로 시작합니다.
- 교사 화면·교사 인쇄에 보여 주는 조합은 **평형 조건(물체 + 왼쪽 추 = 오른쪽 추)으로 도출**한 것입니다. 1·3·9 g을 각각 한 번만 쓰면 1~13 g마다 조합이 하나뿐이어서 도출이 유일합니다(`weightPlans`, 단위 테스트로 13칸 모두 확인). 이 도출은 교재의 정답이 아니므로, 교재·공식 근거로 확인되면 대조해야 합니다.
- 해설 PDF의 다른 단원평가 번호를 Daily Test 번호와 섞지 않습니다.

## 교육 내용 검수 메모 (교재대로 반영, 교사 메모로만 기록)

1. 32쪽 ⑥은 두 상자의 무게를 따로 쓰지 않습니다(⑦에서 “같은 무게의 상자”가 처음 나옴). 체험은 같은 무게의 상자로 조건을 맞췄고 교재 문장은 고치지 않았습니다.
2. 34쪽 서술 중 바퀴가 “6,000여 년 전 수메르에서 만들어졌다”는 내용은 교재의 서술이며 별도로 검증한 연표가 아닙니다. 교재 문장의 띄어쓰기·구두점(“굴러가야하는”, “가해줘야 하고.”, “무게중심이 되고.”)은 고치지 않았습니다.
3. 35쪽 실험의 도면 1·2는 30~35쪽에 실려 있지 않습니다. 수업 전에 도면·준비물과 비탈길 모양을 확인하고 먼저 시연해야 합니다. 교재 서술만으로는 비탈길의 모양을 판단하지 않았습니다. P39의 3D 그림은 마주 붙인 깔때기(쌍뿔)가 넓어지는 V자 비탈길에서 무게중심이 낮아지는 개념 그림이며 실제 실험 결과 사진이 아닙니다.
4. 33쪽 Daily Test는 정답 미인쇄(위 정책).
5. 30쪽 ②③과 31~32쪽의 “무게”는 같은 무게의 상자 개수로 읽습니다. 3차시에서 정리한 무게/질량의 구분(3차시 메모 1)과 같은 표현 문제를 가지고 있으므로 같은 검수 결과를 따릅니다.
