# 지필드 영재교육 과학 교재(실험편·교사용) 차례

## 3-A단계 (실험) — 파일: 3-A단계 실험-교사.pdf
- 1. 통통 튀는 통통볼 — 물체와 물질·탄성(력)·도체/부도체 / 물유리 용액에 알코올을 넣음(5:1)→끈적한 덩어리(고분자)가 생기는지·공이 튀어 오르는지 관찰 (탐구요소: 가설 설정·관찰·예상·결론 도출)
- 2. 달콤한 설탕 사탕 — 물질의 세 가지 상태·상태 변화(물리적 변화, 원인=온도) / 설탕을 가열·냉각→녹았다 굳는 변화, 맛(성질) 유지 여부 (가설 설정·관찰·추리·결론 도출)
- 3. 풍선을 부풀려라! — 기화(액체→기체)·상태 변화 6종·분자 모형 / 알코올 넣은 풍선·비닐장갑을 뜨거운 물에 넣음/식힘→부푸는 정도(종이컵 기준) (가설 설정·예상·추리·결론 도출)
- 4. 꽃밭의 벌과 나비 — 자기력(인력·척력)·자기장·자기력의 투과 / 자석과 모형 사이에 통과시키는 물질(종이·알루미늄포일·OHP필름·철판)→벌·나비 모형이 떠 있는지 (가설 설정·예상·추리·결론 도출)
- 부록(제목만): 꽃밭의 벌과 나비 (3-A-4 — 4번 실험용 꽃·벌·나비 그림 오리기)
- ※ 텍스트는 위 부록 표기에서 끝남. 3-B도 4실험 구성이라 4개가 전부로 보이나, 5번 이후 존재 여부는 텍스트로는 확정 불가.

## 3-B단계 (실험) — 파일: 3-B단계 실험-교사(부록有).pdf
- 1. 철가루 그림 — 자기장·자기력선(N→S)·인력/척력 / 자석 배치(막대·원형, 같은 극/다른 극 마주보기)→철가루가 늘어선 모양 (가설 설정·예상·추리·결론 도출)
- 2. 자석 오리 가족 — 자화·나침반 원리(지구 자석)·자석 성질 없애기 / 클립을 자석 한 면으로 한 방향 문지름→클립끼리 붙는지·연결되는 클립 수 (가설 설정·관찰·추리·결론 도출)
- 3. 나비의 생김새 — 곤충의 몸 구조(머리·가슴·배, 다리 3쌍·날개 2쌍)·나비 vs 나방 / 나비 모형 제작 후 부위 관찰(변인 조작 없음, 관찰·자료 해석·일반화)
- 4. 나비의 한살이 — 완전 탈바꿈 vs 불완전 탈바꿈·보호색·의태 / 여러 나비의 한살이 카드 분류·목걸이 제작(변인 조작 없음, 관찰·분류·일반화·자료 해석)
- 부록(제목만): 자석 오리 가족 (3-B-2, 오리 그림) · 나비의 생김새 (3-B-3, 나비 그림) · 나비의 한살이 부록 2장(한살이 특징·나비카드 사진 — 본문에 언급, 텍스트 미추출)

## 3-C단계 (실험) — 파일: 3-C단계 실험-교사(부록有).pdf
- 1. 곤충 모형 만들기 — 사슴벌레·곤충의 몸 구조(외골격, 머리·가슴·배, 다리 6개)·절지동물·완전 탈바꿈 / 종이 모형 제작 후 부위·다리 수 관찰(변인 조작 없음, 관찰·추리·일반화·자료해석)
- 2. 간이 온도계 만들기 — 온도계 원리(액체의 열팽창)·알코올/수은 온도계·막대 온도계 구조 / 간이 온도계를 담그는 물의 온도(따뜻한 물/찬물)→빨대 속 알코올 기둥의 높이 변화 (가설 설정·관찰·추리·결론 도출)
- 3. 풍향 풍속계 만들기 — 바람의 원인(기압 차)·풍향(불어오는 방향)·풍속·해풍 / 바람의 세기→풍속계 날개가 일정 시간에 도는 횟수, 풍향계 화살표 방향 (가설 설정·예상·관찰·일반화)
- 4. 우량계 만들기 — 강수량·측우기·원기둥 그릇이 알맞은 이유·물의 순환 / 컵의 모양(입구 좁은 컵·플라스틱 컵·원통형 병) 3종에 같은 양(60mL)의 물→고인 물의 높이 비교 (가설 설정·관찰·추리·결론 도출)
- 부록(제목만): 곤충 모형 만들기 (3-C-1, 사슴벌레 부록 2장) · 간이 온도계 만들기 (3-C-2, 온도계 눈금 부록) · 풍향 풍속계 부록(본문에 언급, 텍스트 미추출)
