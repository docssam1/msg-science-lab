# 지필드 영재교육 과학 교재 — 실험편(중등, 교사용) 차례

> 출처: Google Drive `중-NN단계 실험-교사.pdf` 텍스트 추출. 실험 제목·핵심 개념만 기록.

## 중-01단계 (실험, 중등)
- 1. 공중에 자석 띄우기 — 자기력(인력·척력), 힘의 평형, 자기 부상 열차
- 2. 팝콘 만들기 — 상태 변화와 열에너지, 분자 운동·부피 변화
- 3. 풍화 작용의 원인 — 풍화(기계적·화학적), 토양의 생성
- 4. 세포 모형 만들기 — 세포의 구조와 기능, 식물세포·동물세포 비교

## 중-02단계 (실험, 중등)
> `중-02단계 실험-교사.pdf`와 `중-02단계 실험-교사(부록有).pdf`는 **동일**(본문·실험 4개 모두 같음. 차이는 마지막 부록 절취선 표기 "절취선"/"자르는선"뿐).
- 1. 고무줄 자동차 — 탄성력, 마찰력
- 2. 세포막의 역할 — 반투막, 삼투 현상, 선택적 투과성
- 3. 액체 손난로 — 상태 변화와 열에너지(응고열·융해열), 과냉각·과포화
- 4. 화산과 화성암 — 화성암(화산암·심성암), 마그마 냉각 속도와 결정 크기, 조암 광물
- 부록: 중-02-4 화산과 화성암 — 암석 사진 자르기(현무암·안산암·유문암 / 반려암·섬록암·화강암)

## 중-03단계 (실험, 중등)
- 1. 마찰 전기 — 대전·대전열, 전자의 이동, 방전
- 2. 식물의 영양 — 광합성, 녹말 검출(아이오딘 반응), 녹말의 호화
- 3. 방향제 만들기 — 확산, 분자 운동과 온도, 변인(조작·통제·종속)
- 4. 지구 내부의 구조 — 지각·맨틀·외핵·내핵(부피비 계산), 지진파(P파·S파)

## 중-04단계 (실험, 중등)
- 1. 검전기 만들기 — 정전기 유도, 검전기의 원리
- 2. 증산 작용과 공변세포 — 기공의 개폐, 증산 작용, 물의 상승 요인
- 3. 기체의 부피 변화 — 보일 법칙(압력), 샤를 법칙(온도), 기체의 압력
- 4. 움직이는 대륙 — 대륙 이동설, 맨틀 대류, 판 구조론

## 중-05단계 (실험, 중등)
- 1. 새우깡의 열량 — 열량·비열, 에너지 전환, 오차, 기초 대사량
- 2. 침의 역할 — 소화 효소(아밀레이스), 녹말→엿당, 실험군·대조군
- 3. 불꽃 반응 — 금속 원소의 불꽃색, 선 스펙트럼
- 4. 지구의 크기 — 에라토스테네스의 측정 원리(호의 길이∝중심각), 지구 모형 반지름 구하기
- 부록(말미): 키트업체 변경으로 인한 재료 변경사항(2주차 침의 역할 — 녹말 가루)

## 중-06단계 (실험, 중등)
- 1. 간이 보온병 만들기 — 열의 이동(전도·대류·복사), 단열
- 2. 혈액의 순환 — 심장의 구조(2심방 2심실), 체순환·폐순환, 판막
- 3. 분자 모형 만들기 — 원자와 분자, 분자식, 원자 모형의 변천
- 4. 태양계 모형 만들기 — 태양계 행성, 지구형·목성형 행성 분류, 내행성·외행성
- 부록(말미): 키트업체 변경으로 인한 재료 변경사항(1주차 탈지면 규격, 4주차 태양계 사진 부록 자체 제작)

## 중-07단계 (실험, 중등) — 파일명 (부록有)
- 1. 반영의 반영 — 빛의 직진·반사, 만화경(거울 사잇각과 상의 개수)
- 2. 폐의 움직임 — 호흡 운동의 원리(가로막·갈비뼈, 압력 차), 들숨·날숨
- 3. 빛나는 야광볼 — PVA·붕사 화학 반응(플러버), 물리적 변화와 화학적 변화, 고분자
- 4. 반짝반짝 작은 별 — 별의 일주운동·연주운동, 계절별 별자리, 별자리판(축광안료)
- 부록: 중-07-1 반짝반짝 작은 별 — 별자리판 부록 A·B·C (3장)

## 중-08단계 (실험, 중등)
- 1. 내가 만든 팬플룻 — 소리의 3요소(세기·높이·맵시), 진동수·진폭, 소리의 전달 경로
- 2. 효모가 만드는 술 — 무기호흡·유기호흡, 발효와 부패, ATP
- 3. 설탕 과자의 비밀 — 물리적 변화·화학적 변화, 탄산수소나트륨의 열분해, 화합·분해·치환
- 4. 별이 있는 곳은? — 별의 밝기와 등급(겉보기·절대 등급), 등급과 거리, 입체 오리온자리
- ※ 본문에 부록 언급(팬플룻 관 길이 도안, 오리온자리 별 거리·등급 표)이나 추출 텍스트에는 부록 페이지 미포함

## 중-09단계 (실험, 중등)
- 1. 만화영화 만들기 — 잔상 효과(조트로프), 착시, 눈의 구조와 사진기 비교
- 2. 빗면의 원리 — 빗면·나사(나사선, 피치), 힘과 이동 거리의 관계, 쐐기
- 3. 기압이란? — 기압의 크기·작용 방향, 기압 차에 의한 공기 이동, 고기압·저기압
- 4. 액체탑 쌓기 — 농도와 밀도, 밀도 차에 의한 층 분리, 아르키메데스의 원리

## 중-10단계 (실험, 중등) — 파일명 (부록有)
- 1. 에너지의 전환 — 위치 에너지·운동 에너지, 역학적 에너지 전환
- 2. 건강상태 알아보기 — 배설(신장), 오줌의 생성(여과·재흡수·분비), 소변 검사지
- 3. 잉크 꽃잎 — 크로마토그래피(혼합물 분리), 전개율, 모세관 현상
- 4. 날씨 예보하기 — 일기도·등압선, 고기압·저기압의 이동(편서풍), 일기 예보 과정
- 부록: 중-10-2 소변 검사지 색 비교표 / 중-10-4 날씨 예보하기 — 부록1 일기 기호, 부록2 등압선 그리기, 부록3 날씨 예보하기(1~4일 일기도)

## 중-11단계 (실험, 중등)
- 1. 세포가 분열하는 이유 — 세포의 크기와 물질 교환(표면적/부피 비), 세포 분열
- 2. 속도 조절 선풍기 — 전기 저항(가변 저항), 저항과 전류의 관계, 도선의 길이·단면적
- 3. 해류의 운동 — 해류의 발생 원인(바람, 밀도 차), 난류·한류, 우리나라 주변 해류
- 4. 소금물로 글씨 쓰기 — 전해질과 이온, 소금물의 전기분해, 지시약(페놀프탈레인)
- 부록: 중-11-3 해류의 운동 — 우리나라 지도

## 중-12단계 (실험, 중등)
- 1. DNA 모형 만들기 — DNA 이중나선 구조, 뉴클레오티드, 염기의 상보적 결합
- 2. 스타이로폼 칼 만들기 — 전류의 열작용, 전기 에너지→열에너지, 전열기·퓨즈
- 3. 기름 유출을 막아라! — 해양 오염(기름 유출) 방제 원리(오일펜스·흡착제·유화제), 자정 작용
- 4. 소금물 전지 만들기 — 화학 전지(볼타 전지), 금속의 이온화 경향, 전해질
