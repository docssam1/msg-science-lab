# 지필드 영재교육 과학 교재(이론편, 교사용) — 차례

> 출처: Google Drive PDF 8종(텍스트 추출). 단원 번호·제목·소제목만 옮김. 영역은 파일명·심화 단원명 기준.

## 개정 5-1-1단계 (이론) — 지구과학·화학
- Ⅰ. 지구와 달 — 1. 지구와 달의 모양과 표면의 특징 · 2.(누락, 텍스트상 3부터 이어짐) · 3. 지구의 자전 · 4. 하루 동안 달의 움직임 · 5. 여러 날 동안 달의 모양과 위치 변화 [지구과학]
- Ⅱ. 지구 과학 영역 심화 — 1. 지구의 모양 · 2. 지구의 위치를 정하는 방법(위도·경도) · 3. 지구와 달의 크기(에라토스테네스·지구 모형·달의 크기 측정) [지구과학 · 심화]
- Ⅲ. 용해와 용액 — 1. 물과 아세톤에 소금 넣어 보기 · 2. 용해와 용액 · 3. 물과 아세톤에 여러 가지 가루 물질 녹이기 · 4. 물과 아세톤에 잉크 녹여 보기 · 5. 온도와 용질의 녹는 양과의 관계 · 6. 식용유와 글리세롤을 물에 녹이기 · 7. 용해 전과 후의 무게 비교하기 [화학]
- Ⅳ. 화학 영역 심화 — 1. 용액의 농도 · 2. 용액의 종류 · 3. 용해도 · 4. 기체의 용해도 · 5. 입자의 인력과 용해도 [화학 · 심화]
- (각 단원 구성: 개념 잡기 → 개념 확인 → 개념 응용 → 창의사고력 → 재미있는 과학이야기)

## 개정 5-1-2단계 (이론) — 생물·물리
> 단원 번호가 1단계(Ⅰ~Ⅳ)에 이어 Ⅴ부터 시작. 심화 단원 표제는 원문에 "Ⅲ"으로 오기돼 있으나 쪽 하단 표기는 "생물 영역 심화 6."이라 Ⅵ으로 적음.
- Ⅴ. 식물의 구조와 기능 — 1. 뿌리 · 2. 줄기 · 3. 잎 · 4. 꽃과 열매 [생물]
- Ⅵ. 생물 영역 심화 — 1. 현미경으로 식물 관찰하기 · 2. 뿌리의 흡수 작용 · 3. 증산 작용 · 4. 광합성 [생물 · 심화]
- Ⅶ. 물체의 속력 — 1. 움직이는 것과 움직이지 않는 것 · 2. 물체의 빠르기 비교하기 · 3. 여러 가지 속력 비교하기 · 4. 3종 경기 해보기 · 5. 일정한 시간 간격마다 움직인 거리 표시하기 · 6. 물체의 속력과 안전 [물리]
- Ⅷ. 물리 영역 심화 — 1. 힘 · 2. 운동 · 3. 힘이 작용하지 않을 때 물체의 운동 · 4. 힘이 작용할 때 물체의 운동 [물리 · 심화]

## 개정 5-2-1단계 (이론) — 생물
- Ⅰ. 작은 생물의 세계 — 1. 물에 사는 작은 생물 · 2. 땅에 사는 작은 생물 · 3. 작은 생물이 살아가는 환경 · 4. 미생물과 우리 생활과의 관계 [생물]
- Ⅱ. 생물 영역 심화 — 1. 세포와 생물체 · 2. 무성 생식 [생물 · 심화]
- Ⅲ. 우리의 몸 — 1. 뼈와 근육 · 2. 음식물의 소화 과정 · 3. 심장이 하는 일 · 4. 숨을 쉴 때 일어나는 일 · 5. 배설 기관 [생물]
- Ⅳ. 생물 영역 심화 — 1. 자극에 대해 반응하는 과정 · 2. 감각 기관의 구조와 기능 [생물 · 심화]

## 개정 5-2-2단계 (이론) — 물리·지구과학
> 이 파일은 단원 번호가 Ⅰ부터 다시 시작(5-2-1과 별도 번호).
- Ⅰ. 전기 회로 — 1. 전기 회로와 전기 회로도 · 2. 전기 회로도를 보고 예상하고 확인하기 · 3. 여러 가지 방법으로 전구 2개 연결하기 · 4. 전기 회로에서 전류가 흐르는 길 조사하기 · 5. 주변에서 전기 회로의 연결 살펴보기 [물리]
- Ⅱ. 물리 영역 심화 — 1. 대전과 전기력 · 2. 전자의 이동과 대전 · 3. 정전기 유도 [물리 · 심화]
- Ⅲ. 태양과 별 — 1. 태양의 가족 구성원 알아보기 · 2. 태양의 모양 관찰하기 · 3. 행성의 크기 비교하기 · 4. 태양에서 각 행성까지의 거리 비교하기 · 5. 하룻동안 별자리가 움직이는 방향 알아보기 · 6. 계절별 별자리 · 7. 우주 탐사 [지구과학]
- Ⅳ. 지구과학 영역 심화 — 1. 지평 좌표계와 별자리 · 2. 별의 밝기와 등급 · 3. 별의 온도와 색 (원문 주석: 중2 '별과 우주' 중 별 관련 부분만, 연주시차 제외) [지구과학 · 심화]

## 개정 6-1-1단계 (이론) — 화학·물리
- Ⅰ. 산과 염기 — 1. 리트머스 종이와 페놀프탈레인 용액으로 용액 분류하기 · 2. 지시약을 만들어 용액 분류하기 · 3. 생활 주변의 물질의 성질 조사하기 · 4. 산성 용액과 중성 용액을 섞었을 때의 변화 · 5. 생활 속에서 중화 반응을 이용하는 경우 [화학]
- Ⅱ. 화학 영역 심화 — 1. 물질의 구성 · 2. 원소 · 3. 원자 · 4. 분자 [화학 · 심화]
- Ⅲ. 빛 — 1. 빛의 직진 · 2. 빛의 반사 · 3. 우리가 물체를 볼 수 있는 이유 · 4. 거울에 의한 상 · 5. 잠망경 만들기 · 6. 빛의 굴절 · 7. 공기와 물속에서의 빛의 굴절 현상 관찰하기 · 8. 여러 가지 렌즈의 종류 · 렌즈를 통해 보이는 물체의 모습(원문 번호 5.로 오기) [물리]
- Ⅳ. 물리 영역 심화 — 1. 빛의 분산 · 2. 무지개 · 3. 빛의 합성 [물리 · 심화]

## 개정 6-1-2단계 (이론) — 생물·지구과학
> 단원 번호가 1단계(Ⅰ~Ⅳ)에 이어 Ⅴ부터 시작.
- Ⅴ. 생태계와 환경 — 1. 생물이 살아가는 데 필요한 것 · 2. 생물이 양분을 얻는 방법 · 3. 생물 사이의 먹고 먹히는 관계 · 4. 먹이 피라미드 · 5. 생태계의 평형 · 6. 환경오염 [생물]
- Ⅵ. 생물 영역 심화 — 1. 생물 농축의 의미 · 2. 생물 농축을 일으키는 물질과 피해 · 3. 여러 가지 환경오염 [생물 · 심화]
- Ⅶ. 날씨의 변화 — 1. 물의 증발 조건 · 2. 습도계 만들기 · 3. 건습구 습도계를 이용하여 습도 측정하기 · 4. 이슬이 생기는 과정 · 5. 안개가 생기는 과정 · 6. 구름이 생기는 과정 · 7. 비가 내리는 과정 · 8. 바람이 부는 까닭 · 9. 바닷가에서 낮과 밤에 부는 바람의 방향(본문 번호 표기 유실, '배울 내용' 목록 기준) · 10. 기상청에서 하는 일과 일기 예보 과정 · 11. 일기도 · 12. 우리나라의 계절별 날씨 [지구과학]
- Ⅷ. 지구과학 영역 심화 — 1. 물의 증발과 포화 수증기량 · 2. 응결과 이슬점 · 3. 습도 · 4. 구름의 생성 과정 · 5. 눈과 비의 생성 과정 [지구과학 · 심화]

## 개정 6-2-1단계 (이론) — 화학·지구과학
- Ⅰ. 여러 가지 기체 — 1. 힘을 가할 때의 기체의 부피 변화 · 2. 온도에 따른 기체의 부피 변화 · 3. 우리 생활에서 산소가 이용되는 경우 · 4. 산소의 성질 알아보기 · 5. 이산화탄소의 성질 알아보기 · 6. 우리 주위의 여러 가지 기체와 우리 생활의 관계 · 7. 이산화탄소를 줄이는 방법 [화학]
- Ⅱ. 연소와 소화 — 1. 촛불 관찰하기 · 2. 초가 연소할 때 생기는 물질 · 3. 물질이 연소할 때 필요한 것 · 4. 물질이 타기 시작하는 온도(돋보기로 불 붙이기·발화점) · 5. 물질의 발화점 비교하기 · 6. 연소와 소화의 관계(연소의 조건·소화의 조건) · 7. 소화기의 사용법 · 8. 간이 소화기 만들기 [화학] ※ 4·6 제목은 본문 번호 표기가 유실돼 '배울 내용' 목록으로 보충
- Ⅲ. 화학 영역 심화 — 1. 물질의 상태와 분자 배열 · 2. 상태 변화에 따른 분자 운동 · 3. 연소(완전 연소·불완전 연소, 연소 반응 전후 질량 비교) [화학 · 심화]
- Ⅳ. 계절의 변화 — 1. 계절에 따른 기온과 밤낮의 길이 변화 · 2. 태양의 고도에 따른 그림자 길이와 기온 변화 · 3. 태양의 고도에 따른 태양 에너지의 양 · 4. 계절에 따른 태양의 남중 고도·기온·낮의 길이의 관계 · 5. 위도에 따른 태양의 고도와 그림자 길이 변화 · 6. 계절에 따라 태양의 남중 고도가 달라지는 까닭 · 7. 지구의 공전과 계절의 변화 · 8. 해시계를 만들어 시각 재기 [지구과학]

## 개정 6-2-2단계 (이론) — 지구과학·물리
> 단원 번호가 1단계(Ⅰ~Ⅳ)에 이어 Ⅴ부터 시작. 심화 단원(Ⅴ)이 맨 앞에 옴.
- Ⅴ. 지구과학 영역 심화 — 1. 기압 · 2. 기단과 날씨의 변화 · 3. 지구의 자전 · 4. 지구의 공전 [지구과학 · 심화]
- Ⅵ. 에너지 — 1. 에너지 · 2. 에너지 전환 · 3. 지레 · 4. 도르래 · 5. 경사면 [물리]
- Ⅶ. 자기장 — 1. 에나멜선 주위의 나침반 방향 · 2. 고리 모양 에나멜선 주위의 나침반 · 3. 전자석의 특징 · 4. 전자석의 세기에 영향을 주는 요인 [물리]
- Ⅷ. 물리 영역 심화 — 1. 전자기력 · 2. 전동기 · (보충: 전류계·전압계) [물리 · 심화]

### 정리
- 8개 파일 모두 차례 확보(미확보 없음). 파일당 4단원, 총 32단원. 각 학기 1단계는 Ⅰ~Ⅳ, 2단계는 Ⅴ~Ⅷ로 이어짐(예외: 5-2-2단계는 Ⅰ부터 다시 시작).
- 매 파일 = 일반 단원 2 + 해당 영역 '심화' 단원 2. 단원 구성은 공통으로 개념 잡기 → 개념 확인 → 개념 응용 → 창의사고력 → 재미있는 과학이야기.
