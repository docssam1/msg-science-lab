# 지필드 영재교육 과학 교재(실험편·교사용) 차례

> Drive PDF 텍스트에서 실험 제목만 추출. 각 실험은 「미리생각하기 → Step1 가설 → Step2 실험 → Step3 결과 → Step4 결론 → Step5 개념 확장 토의 → Step6 창의력 → 영재성 기르기(TTCT형 발산과제) → 핵심 정리 → 과학 교실」 구조.
> "바꾸는 것→재는 것"은 교재에 조작·종속 변인이 명시된 경우만 적음. 명시 없으면 실험 절차에서 드러나는 것만 괄호로.

## 개정 5-A단계 (실험)
- 1. 달의 모양 변화 — 달의 공전과 위상 변화(삭·초승·상현·망·하현·그믐), 자전=공전 주기, 금환일식 / 달 위치판의 달 모형 위치(반시계 회전)→지구에서 보이는 달의 모양·관측일
- 2. 푸코의 진자 — 지구 자전의 증거, 관성, 코리올리 효과, 자전축 기울기와 계절 / 북극 지도(바닥)를 반시계로 회전→진자의 진동면 방향
- 3. 흰 눈이 펄펄 — 용해도와 온도, 포화·불포화·과포화 용액, 재결정(염화암모늄 눈), 흡열반응 / 용액 온도(식힘·재가열)→석출되는 결정의 양
- 4. 병속에 떠 있는 배 — 극성·비극성 물질, 액체의 층 분리와 비중(메틸렌클로라이드+물) / (병을 기울임·뒤집음)→종이배의 자세
- ※ 텍스트는 32쪽(4번 실험의 「과학 교실」)에서 끝남. 5-B·5-C·5-D도 모두 같은 자리(4번 실험, 32쪽)에서 끝나므로 **단계당 실험 4개**가 실제 구성으로 보임(각 실험 8쪽).

## 개정 5-B단계 (실험)
- 1. 줄기 단면 모형 만들기 — 관다발(물관·체관·형성층), 쌍떡잎/외떡잎식물 줄기 구조 비교, 횡단면·종단면 / (OHP 전개도 모형 제작·비교, 변인 실험 아님)
- 2. 병속 정원 만들기 — 삼투 현상, 반투막(금속염+물유리 화학정원), 용액 농도 / 넣는 금속염 종류(염화코발트·염화구리·염화아연)→색 변화·위쪽으로 자라는 모습
- 3. 스포이트 로켓 — 작용·반작용(뉴턴 제3법칙), 공기 압력, 속력 / 발사 각도(20~70°)·스포이트 끼우는 깊이→날아간 거리·올라간 높이
- 4. 호버크래프트 — 마찰력, 작용·반작용, 등속 직선 운동(CD판 호버크래프트) / 풍선 크기(공기량)→CD판의 움직임·이동 거리
- ※ 텍스트 32쪽(4번 실험 「과학 교실」)에서 끝남 — 실험 4개 구성.

## 개정 5-C단계 (실험)
- 1. 소금쟁이 띄우기 — 표면장력, 응집력·부착력, 계면활성제 / 떨어뜨리는 액체(물·알코올·세제)→소금쟁이(에나멜선)의 움직임·가라앉음; 클립 개수→수면 모양
- 2. 효모빵 만들기 — 효모·발효, 미생물, 출아법(무성생식), 베이킹파우더와 비교 / 반죽 물의 온도(찬물 vs 따뜻한 물 40℃)→반죽이 부푸는 정도·구운 빵의 차이
- 3. 팔근육 모형 만들기 — 근육의 수축·이완, 뼈와 근육(이두근·삼두근), 힘줄·인대 / 우드락(뼈) 오므림·폄→안쪽·바깥쪽 용수철(근육)의 늘어남·줄어듦
- 4. 모형 손가락 만들기 — 뼈와 뼈마디(관절), 연골, 뼈의 생김새와 하는 일 / (빨대 마름모 구멍 크기→실을 당겼을 때 휘어지는 정도)
- ※ 텍스트 32쪽(4번 실험 「과학 교실」)에서 끝남 — 실험 4개 구성.

## 개정 5-D단계 (실험) — 부록有
- 1. 손전등 만들기 — 전기 회로(닫힌/열린 회로), 전지의 직렬·병렬 연결, 전구 구조(필라멘트·꼭지쇠·꼭지), 회로도 기호 / 전지 연결 방법(직렬 vs 병렬)→전구 밝기·전지 사용 시간
- 2. 마찰 전기 장구 — 마찰 전기(대전), 정전기 유도, 접지, 번개·피뢰침 / 마찰시킨 투명관 접근·은박컵에 손가락 접지→알루미늄 공의 움직임(딸깍 소리)
- 3. 떠오르는 태양 — 밀도(비중) 차, 극성·비극성, 표면장력, 태양계 생성(성운설) / 에탄올에 넣는 물의 양→붉은 식용유 덩어리의 높이(가라앉음→떠오름)
- 4. 별자리 액자 — 계절별 별자리, 지구 공전, 황도 12궁(탄생 별자리), 주극성 / (탄생 별자리 액자 제작, 변인 실험 아님)
- 부록: 「별자리 액자 5-D-4」 — 황도 12궁 별자리 그림(물병·물고기·양·황소·쌍둥이·게·사자·처녀·천칭·전갈·사수·염소자리, 날짜 범위 표기)
- ※ 텍스트 32쪽 + 부록 2쪽에서 끝남 — 실험 4개 구성.

## 개정 6-A단계 (실험)
- 1. 카멜레온 캡슐 — 산과 염기, 지시약(만능지시약·BTB·페놀프탈레인·리트머스), pH, 알긴산나트륨+염화칼슘 캡슐화 / 캡슐을 담그는 용액(묽은 염산 vs 묽은 수산화나트륨)→캡슐(지시약)의 색
- 2. 야광봉 만들기 — 화학발광(디페닐옥살레이트+과산화수소), 생물발광(반딧불이·루시페린), 촉매, 야광과 형광 / (유리관 파손 전 vs 후→빛 발생 여부; 열 없이 빛만 남 관찰)
- 3. 신기한 거울 — 빛의 반사(정반사·난반사, 반사의 법칙), 평면·볼록·오목 거울의 상, 왜상(원통 거울), 정영경 / 두 평면거울 사잇각(30·45·60·90·120·180°)→거울에 비친 상의 개수
- 4. 간이 분광기 만들기 — 빛의 분산·회절(CD 회절격자), 스펙트럼(연속/선), 백색광·단색광, 무지개 생성 / 관찰 광원(햇빛·형광등·촛불)→스펙트럼의 모양(연속 vs 불연속)
- 부록 언급: 「간이 분광기 만들기 1·2」 전개도(교재 뒤쪽) — 이 파일에는 부록 텍스트 없음.
- ※ 텍스트 32쪽(4번 실험 「과학 교실」)에서 끝남 — 실험 4개 구성.

## 개정 6-B단계 (실험)
- 1. 산성비 만들기 — 산성비 원인(황산화물·질소산화물), pH 5.6, BTB 지시약, 산성비 피해 / 성냥 연기와 물의 접촉(태우기 전 vs 후)→BTB 용액의 색(초록→노랑)
- 2. 콜라가 사이다로 — 활성탄(숯)의 흡착, 간이 정수기(여과·흡착), 탄소 동소체 / 활성탄·모래 여과층 통과(통과 전 vs 후)→콜라의 색
- 3. 컵 속에 내리는 비 — 물의 상태 변화(증발·응결), 구름·안개·이슬·비의 생성, 흡열반응(염화암모늄), 빙정설·병합설 / 페트리 접시 물의 온도(염화암모늄 용해로 낮춤)→컵 안의 안개·접시 밑 물방울 생성과 낙하
- 4. 그림 습도계 — 습도, 염화코발트의 색 변화(수화물·무수물), 시트르산의 탈수 작용, 건습구 습도계 / 종이의 수분(건조·가열 vs 습한 상태)→염화코발트(붉은↔푸른)·시트르산(무색→갈색) 색 변화
- ※ 텍스트 32쪽(4번 실험 「과학 교실」)에서 끝남 — 실험 4개 구성.

## 개정 6-C단계 (실험)
- 1. 꿈틀대는 뱀 — 과산화수소 분해, 산소의 성질(조연성), 촉매(아이오딘화칼륨·카탈라아제), 기체 용해도와 온도 / 촉매(아이오딘화칼륨) 투입→거품 발생, 깜부기불 투입→불꽃 커짐(산소 확인)
- 2. 비누 고체 연료 만들기 — 연소, 연료의 종류(고체·액체·기체)와 장단점, 겔 상태, 에너지 전환(화학→빛·열) / (비누가루+알코올 고체 연료 점화→타는 시간 측정)
- 3. 연소의 조건 — 연소의 3조건(탈 물질·산소·발화점 이상 온도), 소화의 조건, 분별증류, 기압 변화 / ①물+알코올 적신 손수건 점화→손수건 연소 여부 ②촛불에 컵 덮기(산소 차단)→촛불 꺼짐·컵 속 수면 상승
- 4. 병속의 토네이도 — 기압(고기압·저기압), 토리첼리, 토네이도·태풍 생성 원리, 회전(각운동량) / 병 회전 여부(그냥 뒤집기 vs 반시계 회전)·뚜껑 구멍 크기→물이 떨어지는 모양(깔때기 소용돌이)·속도, 회전 방향
- ※ 텍스트 32쪽(4번 실험 「과학 교실」)에서 끝남 — 실험 4개 구성.

## 개정 6-D단계 (실험)
- 1. 넘치지 않는 컵 — 대기압, 사이펀의 원리(계영배·변기·자격루), 유체 압력(파스칼) / 컵에 붓는 물의 높이(①·②·③, 구부러진 빨대 높이 기준)→물이 아래로 빠지는지 여부
- 2. 늘어나는 팔 — 지레(힘점·받침점·작용점), 1·2·3종 지레, 도구(도르래·빗면), 일의 원리 / (양 끝을 오므림·폄→팔 길이의 변화; 변인 측정 아님)
- 3. 간이 전동기 만들기 — 전자석, 전류의 자기작용(외르스테드), 전동기의 원리, 초인종 회로 / 회전자 에나멜 벗긴 정도(한쪽 전부·다른쪽 절반)→회전자의 한 방향 회전 여부; 전지 수·코일 감은 수→회전 세기
- 4. 건전지 팽이 — 전자기력(플레밍의 왼손 법칙, 오른나사 법칙), 자기장·자기력선, 자기 부상 열차 / 전류 방향(전지 극 연결 방향)→날개(팽이)의 회전 방향; 자석 수·전압→회전 속도
- ※ 텍스트 32쪽(4번 실험 「과학 교실」)에서 끝남 — 실험 4개 구성.
