## 7-1-1단계 (이론, 중등) — 물리·생물

- Ⅱ. 힘과 운동(2) [물리] — 힘이 작용하지 않을 때·작용할 때의 운동 / 훅의 법칙 / 마찰력 / 운동의 법칙 (※ 본문 표제에 "Ⅰ"로 인쇄돼 있으나 꼬리말은 "2. (2)")
- Ⅲ. 생물의 구성과 다양성 [생물] — 현미경 / 세포의 구조와 기능 / 생물의 구성 단계 / 생물 분류
- Ⅳ. 생물 영역 심화 [생물·심화] — 생명 현상의 특성 / 세포설 / 원핵·진핵 세포 / 세포 소기관

## 7-1-2단계 (이론, 중등) — 화학·지학
- Ⅴ. 물질의 상태 변화 [화학] — 물질의 세 가지 상태와 분자 배열 / 상태 변화 / 가열·냉각 곡선, 녹는점·끓는점 / 상태 변화와 에너지 출입
- Ⅵ. 화학 영역 심화 [화학·심화] — 액체의 일반적인 성질 / 결정성·비결정성 고체 / 상평형 그림
- Ⅶ. 지각의 물질과 지표의 변화 [지학] — 조암 광물·광물의 특성 / 암석의 생성과 순환 / 풍화·토양 / 지표의 변화(유수·지하수·파도·바람·빙하)
- Ⅷ. 지구과학 영역 심화 [지학·심화] — 화산 분출물 / 화산의 형태 / 퇴적 구조 / 퇴적암의 형성 과정
- (※ 7학년 4권은 Ⅰ~ⅩⅥ 연속 번호. 첫머리에 "용어의 변화(7차→개정)" 표 수록)

## 7-2-1단계 (이론, 중등) — 물리·생물
