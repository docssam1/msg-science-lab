## 3. 교재 구조 (문항·활동 소스로 쓸 때)

- **이론편 단원**: 배울 내용 → 개념 잡기(용어사전·핵심질문·강의Tip) → **개념 확인 8**(객관식) → **개념 응용 4**(서술) → **창의사고력 3** → 재미있는 과학이야기 → (심화 단원: 개념 심화·경시 유형) → 워크북 8(3학년만) → 정답 및 해설.
  → 문제은행 소스: 개념 확인=개념 확인형, 개념 응용=서술형, 창의사고력=창의적 문제해결형, 경시 유형=level 3.
- **실험편 실험**(단계당 4개, 실험당 8쪽): 도입 → 미리 생각하기 → Step1 가설 → Step2 실험(준비물·과정·강의Tip·Q) → Step3 결과 기록 → Step4 결론 도출 → Step5 개념 확장 토의 → Step6 창의력 키우기 → **영재성 기르기**(유창성·독창성·민감성 채점 기준) → 과학 교실 → 재미있는 과학이야기.
  → 5E 매핑: 미리 생각하기=①궁금, Step1~4=②실험, 과학 교실=③개념, Step5·6·영재성 기르기=④확장, Q=⑤점검.
- **NEW STUDY pptx**(지필드 강의 슬라이드, Ⅰ 고체·액체·기체 50장): 단원 = Lecture 1~4강 + Laboratory + Mini Test. 강 = 핵심 문장 인용 → **빈칸 개념**(클릭하면 정답 공개) → 성질 정리표(고체/액체/기체 × 모양·부피·압축성·흐름·운동) → 영상(wmv) → Mini Test(①~⑤ 객관식 + 서술). Laboratory = 관찰 Q1·Q2 → 재료 → 가설 빈칸 → 과정·관찰 → 결과 → 그림으로 표현 → 더 알아보기 → "실험하러 가기".
